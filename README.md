# Cricket Army

Web design for Cricket Army (CrickBuster), modelled on the News18 cricket section.

Static site, no build step: open `index.html`.

- `css/styles.css`: design tokens at the top. **Set `--brand` to the exact Cricket Army primary colour.**
- `js/data.js`: sample content (swap for API/CMS data)
- `js/components.js`: reusable components (Header, ScoreChip, MatchCard, NewsCard, RankingList, PointsTable, VideoCard, SeriesCard, Photo, Footer)
- `js/app.js`: page assembly and tab/menu interactions
