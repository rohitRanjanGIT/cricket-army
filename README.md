# Cricket Army

Web design for Cricket Army (CrickBuster), modelled on the News18 cricket section.

Plain HTML, CSS and JavaScript. No build step: open `index.html` in a browser.

- `index.html`: page shell
- `styles.css`: styling. Design tokens at the top; **set `--brand` to the exact Cricket Army primary colour.**
- `index.js`: sample data, reusable components (Header, ScoreChip, MatchCard, NewsCard, RankingList, PointsTable, VideoCard, SeriesCard, Photo, Footer) and page setup
